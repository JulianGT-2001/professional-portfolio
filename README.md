# 🚀 Portafolio Profesional – Fullstack Developer

Este repositorio contiene el código fuente de mi **portafolio profesional como Fullstack Developer**, desarrollado con **React.js y Vite.js**.  
El objetivo del portafolio es presentar de forma clara y moderna:

- Las **tecnologías que manejo**
- Mis **proyectos personales**
- Mi enfoque como desarrollador orientado a soluciones web escalables y bien estructuradas

El proyecto está desplegado mediante **GitHub Pages**, utilizando una rama dedicada (`gh-pages`) para el entorno de producción.

---

## 🧩 Descripción del repositorio

El repositorio cuenta con dos ramas principales:

- **`main`**: contiene el código fuente del proyecto (entorno de desarrollo).
- **`gh-pages`**: contiene el build de producción generado por Vite, utilizado para el deploy en GitHub Pages.

### 📁 Estructura del proyecto (rama `main`)

```
react-project/
```

## ✅ Requisitos previos

Antes de ejecutar el proyecto, asegúrate de tener instalado:

- Node.js (v18 o superior)
- npm o gestor de paquetes compatible
- Git

Verifica las versiones con:

```bash
node -v
npm -v
git --version
```

---

## ⚙️ Instalación y ejecución local

Sigue estos pasos para ejecutar el proyecto en tu entorno local:

1️⃣ Clona el repositorio:

```bash
git clone https://github.com/tu-usuario/tu-repositorio.git
```

2️⃣ Accede al proyecto:

```bash
cd react-project
```

3️⃣ Instala las dependencias:

```bash
npm install
```

4️⃣ Ejecuta el entorno de desarrollo:

```bash
npm run dev
```

5️⃣ Abre el navegador en:

```arduino
http://localhost:5173
```

---

## 🚀 Build y Deploy

Para generar el build de producción:

```bash
npm run build
```

Para previsualizar el build:

```bash
npm run preview
```

El deploy se realiza automáticamente a la rama gh-pages, desde donde GitHub Pages sirve la aplicación en producción.
